# Socket-IO-Learning

A day's worth of spiking following an online tutorial for how Socket.IO works. This is done with the purpose of completing the Northcoders final group project.

This simple web app is located on a localhost server. Simply npm install all dependencies, then hit npm start in the terminal. It should launch nodemon, then follow the ctrl-click link. From there, experiment with the tabs in your browser and begin talking to yourself by establishing a guest username, then creating a chat room to join. You can now begin talking to yourself via two tabs. Maybe one day I might host it on an actual server?

TO confirm it works, check the console inside the Visual Studio terminal (or whatever coding software yu use.) You should see Socket.IO IDs in the terminal showing users are loading the site, and then joining the rooms they select.
